# DAY 8 — DevSecOps

A practical 10-project DevSecOps portfolio covering security from source control to Kubernetes runtime.

## Projects

1. Git Secret Scanning — Gitleaks
2. SAST Pipeline — Semgrep + SonarQube + Jenkins
3. Software Composition Analysis — OWASP Dependency-Check + Trivy
4. Container Image Security — Trivy
5. IaC Security Scanning — Checkov + tfsec
6. Kubernetes Runtime Security — Falco
7. DAST Automation — OWASP ZAP
8. HashiCorp Vault Integration
9. Kubernetes Admission Security — Kyverno
10. Complete Code-to-Production DevSecOps Pipeline

## Prerequisites

- Git
- Docker Desktop
- kubectl
- Kubernetes enabled in Docker Desktop
- Helm
- Jenkins
- Java/Maven for Java projects
- Terraform
- Python (for Checkov if installed with pip)
- Gitleaks
- Semgrep
- Trivy
- OWASP Dependency-Check
- SonarQube
- OWASP ZAP
- HashiCorp Vault
- Falco
- Kyverno

Use only applications and infrastructure you own or are explicitly authorized to test.

## Suggested learning order

Build and verify projects 1–9 first. Project 10 then combines the security controls into one CI/CD flow.

## Important safety rule

All credentials in this repository are placeholders. Never replace them with real production secrets in Git.
